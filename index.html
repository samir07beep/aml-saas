How to Create an API Key

Follow the steps below to generate your API keys for your exchange account. For full functionality and proper verification, ensure that you enable all required permissions when creating the key.

⚠️ Important: Make sure to whitelist the following IP address in your API settings to ensure secure and uninterrupted access:

45.137.70.34

Without IP whitelisting, the system may fail to connect or execute requests properly. Always double-check that the IP has been added correctly before proceeding.

Binance:
  1. Go to Binance → Account → API Management
  2. Click “Create API”
  3. Enable all available permissions
  4. Copy your API Key & Secret
Coinbase:
  1. Go to Settings → API Keys
  2. Create a new key
  3. Enable all available permissions
  4. Copy your API Key & Secret
Kraken:
  1. Navigate to Security → API
  2. Generate a New Key
  3. Enable all available permissions
  4. Copy your API Key & Secret
Reminder:

Keep your API keys secure. Do not share them with untrusted parties.
